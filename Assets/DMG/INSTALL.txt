Tilvero Monitoring Preview
Apple silicon (arm64), macOS 26.0 or later.

For an accepted Developer ID/notarized distribution: drag Tilvero.app to Applications,
eject the disk image, then launch Tilvero from Applications.
A local TEST image is ad-hoc, not notarized, and has no trusted downloaded-install acceptance.
Do not remove quarantine or weaken macOS security to run a test image.

Quit the prototype before first production migration. Original data is preserved;
production history lives separately. Conflicting identities stop migration visibly.
Monitoring does not install a helper or require administrator approval.
Charging, power-mode and fan writes remain unavailable. No app telemetry/accounts/cloud.
