## Review focus

1. Source archives, untrusted metadata, and wrong identity/profile can never become executable candidates.
2. Offline/cancel/older/equal/unknown builds cannot yield a false up-to-date result or stale executable action.
3. Every installer entry and resumed/quit path must require consent and fresh verified recovery; checking must never restore hardware.
4. Monitoring feed is immutable per profile; channel preference never changes capabilities or permits downgrade.
5. Framework embedding/signing and license notices must work in both build routes without weakening gates.
