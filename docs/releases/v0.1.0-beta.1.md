# Tilvero 0.1.0-beta.1 — Source Preview

This first prerelease distributes **source code for developers**. It includes no ready-to-install Mac app or DMG. Build requirements: Apple silicon, macOS 26.0+ and a compatible full Xcode installation with Swift 6 support.

## In this preview

- Native menu-bar and detail views for battery, power and charging information.
- 115 source-aware catalog fields, with unavailable values and measurement limits preserved.
- Searchable application activity and CPU-only energy/power estimates.
- Local history, charts, recorded gaps, sleep/wake reports and previewable exports.
- Configurable quick-panel composition, English/Russian UI and indicator sizing.
- Clear saved-session diagnostics without a permanent banner across normal pages.

The repository also contains development controls. Keep Mac Awake and keyboard-backlight actions use their existing normal-user paths; native charge changes require local per-Mac admission/readback/restoration. Privileged power/fan actions and full-once/cutoff support retain separate gates. A saved mode is not an applied mode. The future monitoring-only DMG disables these control paths and Keep Mac Awake; its distribution is not claimed by this source release.

Application power is derived from CPU counters, not total app electricity or a battery percentage. Live macOS Energy Impact is not implemented. Missing/denied readings remain unavailable; sleep gaps are not attributed to historical apps.

## Files and verification

- `Tilvero-0.1.0-beta.1-source.zip`: exact corresponding source, original assets and licenses.
- `source-release.json`: commit/tag/version, build requirements and source-archive size/hash; explicitly no binary included.
- `SHA256SUMS`: checksums of the ZIP and manifest.

```sh
shasum -a 256 -c SHA256SUMS
```

For full committed-tree verification, use the source CLI from a checkout containing the manifest commit; see [testing](../TESTING.md). The README gallery is native UI rendered with explicitly labeled demo fixtures. Decorative artwork is not a device measurement or distribution-validation claim.

## По-русски

Первый предварительный выпуск содержит **исходники для разработчиков**, без готового `.app` или DMG. Для сборки нужны Apple silicon, macOS 26.0+ и совместимый полный Xcode со Swift 6.

Доступны нативный интерфейс, показания батареи и питания с источниками/актуальностью, 115 полей каталога, активность процессов, локальная история, графики, отчёты сна и экспорт. Возможности управления в исходниках имеют отдельные ограничения и проверки; будущая Monitoring Preview DMG их отключает. Подписанный и нотарифицированный установщик этим выпуском не заявляется.

Оценка мощности приложений относится к CPU; это не полное электропотребление приложения. Живой системный Energy Impact пока не подключён. Галерея показывает настоящий интерфейс с явно помеченными демонстрационными данными.

Скачайте ZIP, `source-release.json` и `SHA256SUMS`, проверьте суммы командой выше и следуйте [инструкции сборки](../INSTALL.md). Исходники распространяются по GPL-3.0-only с сохранёнными сторонними уведомлениями.
